# Claude Code Project Rules

## Language & Communication
- **ALWAYS communicate and respond in Czech.**
- **Translate all technical explanations and summaries into Czech.**

## Decision Making & Uncertainty
- **If you are unsure or lack sufficient information, ALWAYS ask for clarification first.**
- **Immediately request internet access permission if you need to look up documentation or current data.**
- **Be concise, technical, and direct.**
- **Avoid over-analyzing simple tasks and do not make far-reaching architectural conclusions unless explicitly requested.**

## File Management & Organization
- **Keep all your working files, cache, and indexes exclusively within the `.claude/` directory.**
- **Do not create any additional files in the root directory unless they are essential for the codebase.**
- **Focus strictly on files relevant to the current task; ignore unrelated context.**

## Project Maintenance
- **Always wait for explicit confirmation before starting any large-scale refactoring or major changes.**
